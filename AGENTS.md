## 1. Core Application Architecture

### Language & Platform
- **Language**: Kotlin (100%). No Java source files in the main application layer.
- **Platform**: Android (minSdk 21, targets modern API). Build system is **Gradle** with Groovy DSL (`app/build.gradle`).
- **UI Layer**: Hybrid — legacy screens use **Fragments + RecyclerView** (XML layouts, ViewBinding); modern screens are written in **Jetpack Compose** with Material3.

### UI Framework Breakdown
| Module | Stack |
|---|---|
| Download/Library screen | Jetpack Compose (`DownloadScreen.kt`) |
| Modern Novel Detail | Jetpack Compose (`ResultDetailModernScreen.kt`) |
| For You / Recommendations | Jetpack Compose (`ForYouScreen.kt`) |
| History, Search | Jetpack Compose |
| Reader (`ReadActivity2`) | Fragment + XML + Custom `TextAdapter` |
| Navigation host | `androidx.navigation` fragment-based |

### Core Abstractions
- **`MainAPI`** (`MainAPI.kt`): Abstract base for all novel source providers. Each source implements `search()`, `load()`, `loadHtml()`, and optional `loadMainPage()`. Sources live under `providers/`.
- **`LoadResponse`** (interface): Core data contract returned by every provider `load()`. Concrete types: `StreamResponse` (chapter list) and `EpubResponse` (download links).
- **`ChapterData`**: Flat data model `(name, url, dateOfRelease?, views?)` used for chapter lists.
- **`SearchResponse`**: Flat model returned by `search()` with `name`, `url`, `posterUrl`, `apiName`, and optional `posterHeaders`.

### Plugin / Provider Pattern
Sources are loaded dynamically at runtime via plugin context. Each `MainAPI` subclass sets `pluginContext` to its plugin's `android.content.Context`, enabling sandboxed resource access. Rate limiting is enforced per-provider via `rateLimitTime: Long` and `rateLimitMutex: Mutex`.

## 2. State Management & Data Pipelines

### Resource Wrapper (`mvvm/ArchComponentExt.kt`)
All async operations return `Resource<T>`, a sealed class:
```kotlin
sealed class Resource<out T> {
    data class Success<out T>(val value: T) : Resource<T>()
    data class Failure(val cause: Throwable?, val errorString: String) : Resource<Nothing>()
    data class Loading(val url: String? = null) : Resource<Nothing>()
}
```
Use `safeApiCall { }` to wrap any IO call — it runs on `Dispatchers.IO` and converts all `Throwable` types via `throwableToResource()` into typed `Resource.Failure` messages (handles `SocketTimeoutException`, `UnknownHostException`, `SSLHandshakeException`, etc. explicitly).

### ViewModel → UI Flow
- ViewModels expose `MutableLiveData<Resource<T>>` or `MutableStateFlow<T>` observed via `.observeAsState()` in Compose.
- Background coroutines: use `viewModelScope.launchSafe { }` (wraps launch with top-level catch) or `ioSafe { }` for fire-and-forget IO work.
- Use `Dispatchers.Default` for **CPU-heavy sorting/filtering** (see `DownloadViewModel.resortAllData()`), `Dispatchers.IO` for DB/network, `Dispatchers.Main` for UI updates.

### DataStore Pattern (`DataStore.kt`)
- Persistence layer is **`SharedPreferences`** with Jackson JSON serialization for complex types.
- `DataStore.mapper` is a globally reused `JsonMapper` with `FAIL_ON_UNKNOWN_PROPERTIES = false` (forward-compatibility safe).
- Typed accessors: `Context.setKey(path, value)`, `Context.getKey<T>(path)`, and batch `Editor.setKey(path, value)` → `.apply()`.
- **Preference files**: `"rebuild_preference"` (app data) vs `PreferenceManager.getDefaultSharedPreferences()` (settings UI).
- New code should use typed objects from `PreferenceKeys.kt` (`ReaderPrefs.TEXT_SIZE`) not raw legacy constants.

### Room Database (`db/`)
- **SSOT**: `NovelEntity` (table `novel`) is the canonical persistent record for downloaded/bookmarked novels.
- `NovelDao` exposes `getAllAsFlow()` and `getAllBookmarksAsFlow()` — Kotlin Flows consumed in `DownloadViewModel.init {}` for reactive live updates.
- `bookmarkType: Int?` and `downloadStatus: Int?` in `NovelEntity` are the ground-truth for library/bookmark state — always update Room, not only `SharedPreferences`.

### Download Engine
- `BookDownloader2` manages download state (`currentDownloads`, `downloadProgress`, `downloadData`) using `ConcurrentHashMap`, `CopyOnWriteArrayList`, and `Mutex`/`Semaphore` for thread safety.
- Progress updates flow via operator-overloaded event lists (`BookDownloader2.downloadProgressChanged += ::handler`). Always clean up in `ViewModel.onCleared()`.

## 3. Performance & Design Standards

### Compose Optimization Rules
- **No inline lambdas in hot paths**: Hoist state; use `remember { }` and `derivedStateOf { }` for computed values.
- **Sorting is always on `Dispatchers.Default`**, never on `Dispatchers.Main`, to avoid ANRs with large library lists (up to 10k items).
- **List rendering**: `LazyColumn`/`LazyVerticalGrid` with stable `key` lambdas. Never use `distinctBy` inside composition — filter upstream in the ViewModel.
- **RecyclerView** (legacy reader): `chapterAdapter.submitList()` for lists ≤ 300 items; `chapterAdapter.submitIncomparableList()` for larger lists (bypasses DiffUtil for performance).

### Image Loading (Coil 3)
Always use the project's `rememberHighQualityRequest(data, context)` helper for novel covers:
```kotlin
baseRequest.newBuilder(context)
    .allowHardware(true)          // GPU-accelerated bilinear filtering
    .size(coil3.size.Size.ORIGINAL) // No downscale compression
    .crossfade(300)
    .build()
```
For standard cards, use `rememberImageRequest(data)` from `ComposeUtils.kt`, which resolves `ResultCached`, `DownloadDataLoaded`, and `UiImage` polymorphically — including locally cached cover files from `filesDir`.

### Theme System (`ui/theme/`)
The app supports four themes driven by `R.string.theme_key` SharedPreference:
| Theme Key | Description |
|---|---|
| `"Amoled"` (default) | Pure `Color.Black` background, OLED-optimized |
| `"Black"` | Alias for Amoled |
| `"Light"` | Light gray surface palette |
| `"Monet"` | Android 12+ dynamic wallpaper colors via `dynamicDarkColorScheme()` |

`QuickNovelTheme` reads the active theme from `PreferenceManager` at composition time and builds the `MaterialTheme` color scheme dynamically. Status bar is always transparent (`Color.TRANSPARENT`), with `isAppearanceLightStatusBars` matching the theme.

### Glassmorphism Design System
The **Spatial Glass** aesthetic is mandatory for all new Compose surfaces:
- Use `Modifier.glassCard(shape, backgroundColor?, strokeColor?, strokeWidth)` from `Glassmorphism.kt`.
- AMOLED/Black themes resolve to `Color(0xCC000000)` glass; Light themes resolve to `Color(0xEEFFFFFF)`.
- **Hero layout**: Fixed `HERO_HEIGHT = 380.dp`, `HERO_CORNER = 48.dp` (rounded bottom corners on poster). Content card overlaps with `glassCard(RoundedCornerShape(topStart = 28.dp, topEnd = 28.dp))`.

### Animation Standards
- Indicator / traveler animations: `animateFloatAsState` or `animateDpAsState` with `spring(dampingRatio = Spring.DampingRatioLowBouncy, stiffness = Spring.StiffnessMediumLow)`.
- Shimmer skeletons: `InfiniteTransition` + `animateFloat` with `infiniteRepeatable(tween(1000, easing = LinearEasing), RepeatMode.Restart)` and a diagonal `Brush.linearGradient`.
- Page transitions: `pagerState.animateScrollToPage()` — never `scrollToPage()`.
- Section dividers in Compose code comments use Unicode style: `// ─── Section Name ──────────────────────`.

## 4. Conventions, Error Handling & Workflows

### Naming Conventions
| Element | Style | Example |
|---|---|---|
| Composables | `UpperCamelCase` | `ShimmerSkeletonScreen`, `PremiumTabRow` |
| ViewModels | `UpperCamelCase` + `ViewModel` suffix | `DownloadViewModel`, `ResultViewModel` |
| Coroutine helpers / fns | `lowerCamelCase` | `shimmerBrush`, `launchSafe` |
| Constants / Dimensions | `UPPER_SNAKE_CASE` | `HERO_HEIGHT`, `ALPHA_SORT` |
| PreferenceKeys | `UPPER_SNAKE_CASE` string constants | `DOWNLOAD_SORTING_METHOD`, `EPUB_TEXT_SIZE` |
| Source files | `UpperCamelCase.kt` matching contained class/object | `DownloadViewModel.kt` |
| Providers | Suffix with `Provider` | `WuxiaWorldProvider.kt` |

### Import Policy
- Star imports are **only** permitted for these Compose packages:
  - `androidx.compose.foundation.layout.*`
  - `androidx.compose.material.icons.filled.*`
  - `androidx.compose.runtime.*`
- All project types, models, and ViewModels must be explicitly named imports.
- Group imports: `android.*` → `androidx.*` → `coil3.*` → `com.fasterxml.*` → `com.lagradost.*` → `kotlinx.*`.

### Error Handling
- **Never use `!!`** (non-null assertion). Use `?: return`, `?: return@launch`, or `let { }`.
- Wrap all IO/JSON operations in `try { } catch (t: Throwable) { logError(t) }` (not `catch (e: Exception)` — catches `Error` subtypes too).
- Use `safeApiCall { }` for suspend functions returning `Resource<T>`.
- Use `launchSafe { }` / `ioSafe { }` for fire-and-forget coroutines that must not crash the UI.
- Network errors mapped in `throwableToMessage()`: always surface human-readable strings, not stack traces, in UI.

### Local-First Architecture
- All user library data (bookmarks, download state, reading progress) lives in **Room DB + SharedPreferences** on-device.
- No mandatory cloud backend. Sync features (e.g., sync toggle in ResultDetail) are purely optional and user-controlled.
- Provider scrapers are stateless — they fetch on demand; no server-side session state.

## 5. Build, Lint & Test Commands

All commands run from the **project root** directory. Do not run Gradle from subdirectories.

### Build
```bash
# Assemble debug APK
./gradlew assembleDebug

# Clean + full build (bypasses cache)
./gradlew clean build

# List all available tasks
./gradlew tasks
```

### Lint
```bash
# Android lint for debug variant
./gradlew :app:lintDebug

# Inspect dependency tree
./gradlew :app:dependencies
```

### Unit Tests (`app/src/test/`)
All tests are pure JVM (no Android instrumentation required). Test classes are in `com.lagradost.quicknovel.*`.

```bash
# Run ALL unit tests
./gradlew :app:testDebugUnitTest

# Run a specific test CLASS
./gradlew :app:testDebugUnitTest --tests "com.lagradost.quicknovel.util.ParCollectionsTest"

# Run a specific test METHOD (use exact backtick-quoted name)
./gradlew :app:testDebugUnitTest --tests "com.lagradost.quicknovel.util.ParCollectionsTest.pmap transforms every element"

# Wildcard match on class or method name
./gradlew :app:testDebugUnitTest --tests "*ParCollectionsTest*"
./gradlew :app:testDebugUnitTest --tests "*AppUtilsTest*"
```

### Instrumented Tests (`app/src/androidTest/`)
```bash

./gradlew :app:connectedDebugAndroidTest
```
